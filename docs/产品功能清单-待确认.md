## 1. 产品定位

跨平台音乐播放器（首版 Windows 桌面），核心能力：

1. **多源搜索**：本地音乐库 + 第三方音源（网络）聚合搜索；
2. **自有会员**：用户使用自己的第三方 API / 会员账号登录后搜索与播放（不内置任何平台的解析与破解能力）；
3. **歌词**：行级/逐字歌词、桌面悬浮歌词；
4. **常见播放器能力**：播放队列、歌单、收藏、播放历史、主题、托盘、媒体键等。

### 合规红线（不可协商，任何功能设计不得突破）

- 主程序**不内置**任何平台的搜索/歌单/详情/播放解析/登录协议实现；
- 第三方音源以**插件**形式提供，由用户自行获取安装，主程序不内置源、不提供官方源索引；
- **不提供** VIP 破解、加密音频解密、接口签名绕过等能力；
- 凭据加密存储、日志脱敏、不上传。

> 以上来自 `research/01-legal-and-plugin-ecosystem.md` 与 `00-初步调研-总报告.md` 的结论；如你要调整，需要单独确认（风险会同步说明）。
